# 대시보드 정보 구조 (Information Architecture)

이 문서는 `final_analysis_framework.md`에 정의된 지표/Gap/장벽/병목 프로파일을 23개국 전체를 탐색하는
대시보드로 구현하기 위한 정보 구조를 설계한다. 이번 단계에서는 실제 프론트엔드 코드를 작성하지 않는다.

프로젝트 핵심 질문이 "어떤 국가를 공략해야 하는가"가 아니므로, 이 IA의 모든 화면은 **국가를 추천하거나
순위를 매기지 않고, 사용자가 스스로 패턴을 탐색하도록** 설계한다. 어떤 화면에도 "우선순위 국가", "추천
국가", "공략 대상" 섹션은 존재하지 않는다.

## 화면 구조 개요

```
┌─────────────────────────────────────────────┐
│  Overview (진입 화면)                          │
│  23개국 전체 패턴을 한눈에 탐색                    │
└─────────────────────────────────────────────┘
        │           │            │
        ▼           ▼            ▼
┌───────────┐ ┌───────────┐ ┌───────────┐
│  Country   │ │    Gap     │ │  Barrier   │
│  Explorer  │ │  Explorer  │ │  Explorer  │
└───────────┘ └───────────┘ └───────────┘
        │           │            │
        └───────────┴────────────┘
                    ▼
            ┌───────────────┐
            │   Comparison   │
            │ (2~3개국 병렬)   │
            └───────────────┘

  (모든 화면에서 AI Analyst 패널을 열 수 있음 — ai_analysis_interface_spec.md 참조)
```

## 1. Overview

**목적**: "단순 순위표"가 아니라 23개국의 전체적인 분포와 패턴을 탐색하는 화면. 사용자가 "어떤 국가가
1등인가"를 찾지 않고 "국가들이 어떻게 흩어져 있는가"를 보게 만드는 것이 목표다.

**구성 요소**:
- **분포 개요**: Layer1~3 6개 핵심 지표 각각의 23개국 분포(min/q1/median/q3/max, `country_indicator_
  distribution.csv`)를 dot plot으로 제시. "1위 국가"를 강조하지 않고 전체 분포 모양을 보여준다.
- **Direct Gap × Barrier 산점도**: 국가명이 라벨된 산점도(이미 `figures/`에 생성된 4종 참조)를 기본 배치.
  "이 사분면이 좋다/나쁘다"는 주석을 달지 않는다.
- **국가 그리드**: 23개국을 알파벳/한글 가나다 순으로 나열한 카드 그리드. 각 카드는 country_profile_base.csv
  요약값(문화경험률, 방한의향률, Direct Gap, 주요 장벽 1개)만 표시하고, 카드 클릭 시 Country Explorer로 이동.
  카드 정렬 기본값은 "국가명 순"이며, 사용자가 원할 경우에만 특정 지표 기준 정렬을 선택할 수 있게 하되
  "순위"라는 표현 대신 "정렬 기준"이라는 표현을 쓴다.
- **병목 프로파일 요약**: Type A~G 7개 유형 각각의 소속 국가 수(`bottleneck_type_summary.csv`)를 스택형
  바로 제시 — "이 유형이 위험하다"가 아니라 "이런 조합이 관찰된다"는 톤으로 캡션을 단다.

**의도적으로 배제한 것**: 국가 순위 테이블(1위~23위), "TOP 5 국가", 종합점수, 색상으로 국가를 좋음/나쁨
2분할하는 시각화.

## 2. Country Explorer

**목적**: 사용자가 국가 하나를 선택하면 그 국가의 전체 프로파일을 확인.

**구성 요소** (국가 선택 드롭다운/검색 + 아래 프로필 카드):
1. Layer1~3 지표: 문화경험률, 한류인식긍정률(1-35, 별도 패널 표시 포함), 문화→호감도, 방한의향률, 문화→방문의향
   — 각 지표 옆에 23개국 중 tercile 위치(하위/중위/상위)를 함께 표기하되 "낮음/높음" 대신 "하위3분위/상위3분위"
   라는 중립적 용어 사용
2. Direct Gap, Conditional Gap 값 + 두 Gap이 BASE가 다른 별개 지표라는 안내 문구(고정 노출)
3. 주요 장벽 Top3 (B13-1A) + 방문 비의향자 표본 수 + 소표본 여부
4. 병목 프로파일: 이 국가가 속한 Type(A~G) 목록과 각 Type의 판정 근거(어떤 장벽/Gap이 상위3분위였는지)
5. BASE/표본 요약 테이블: 지표별로 어떤 BASE·표본 크기에서 나온 값인지 한 번에 정리
6. 주의사항 박스: `country_bottleneck_profile.csv`의 `interpretation_caution` 텍스트를 그대로 노출(문구
   임의 수정 금지)

**의도적으로 배제한 것**: "이 국가는 공략 우선순위가 높다/낮다"는 식의 결론 문장.

## 3. Gap Explorer

**목적**: Direct Gap과 Conditional Gap을 각각 독립적으로 탐색. 두 Gap을 절대 하나로 합치지 않는다는 원칙을
화면에서도 구조적으로 강제(같은 화면 안에서도 시각적으로 구분된 두 개의 독립 섹션으로 배치, 하나의 합산
그래프로 만들지 않음).

**구성 요소**:
- 상단 고정 설명 배너: "Direct Gap(E1A-1↔B5B-1)은 전체 응답자 BASE, Conditional Gap(E4-1↔E4-3)은 문화경험자
  하위집합 BASE — 서로 다른 모집단에서 계산된 별개의 값입니다"
- Direct Gap 섹션: 23개국 dumbbell chart(문화경험률과 방한의향률 두 점 + 간격), 분포 통계
- Conditional Gap 섹션: 동일한 형식의 별도 dumbbell chart(문화→호감도, 문화→방문의향)
- (선택적 보조 뷰) Direct Gap × Conditional Gap 산점도 — r=0.311(p=0.149)이라는 값과 함께 "약~중간 정도의
  경향, 인과관계 아님" 캡션 고정 노출
- 1-35 참고 배너: "1-35(한류실태조사)는 별도 패널이므로 이 화면의 Gap 계산에 포함되지 않습니다"

## 4. Barrier Explorer

**목적**: 8개 장벽을 국가별로 비교. 방문 비의향자 BASE라는 점과 소표본 여부를 항상 함께 표시.

**구성 요소**:
- Heatmap: 행=23개국, 열=8개 장벽(5개 그룹으로 시각적 구획), 값=비율(%). 소표본 4개국 행은 별도 해칭
  패턴이나 테두리로 표시(색상 강도로만 구분하지 않음 — 값이 작아 보여도 신뢰도가 낮다는 것이 함께 드러나야
  하므로)
- 상단 고정 배너: "아래 비율은 각 국가의 '방문 비의향자'만을 대상으로 한 응답입니다. 국가 전체 인구의 비율이
  아닙니다."
- 장벽 그룹 필터: 인지/관심, 이미지, 경제/물리적 접근성, 제도/언어, 종교/문화환경 — 그룹 단위로 보기/개별
  장벽으로 보기 토글
- 국가별 표본 수 사이드 컬럼(항상 노출, 숨기지 않음)

## 5. Comparison

**목적**: 사용자가 2~3개국을 임의로 선택해 나란히 비교. 추천 조합을 제시하지 않는다.

**구성 요소**:
- 국가 선택기(최소 2개, 최대 3개, 자유 선택 — 기본 선택값을 미리 채워두지 않음)
- 선택된 국가들의 Country Explorer 카드를 나란히 배치(레이더 차트 등 단일 종합점수화된 시각화는 사용하지
  않음 — 지표별 개별 bar/line 비교로 한정)
- Gap, 장벽도 동일한 병렬 비교 형식 유지

**의도적으로 배제한 것**: "어느 국가가 더 낫다"는 자동 판정 텍스트, 비교 결과에 대한 종합 스코어.

## 6. 시각화 설계 원칙

| 데이터 | 시각화 | 선택 이유 |
|---|---|---|
| 국가별 Layer1~3 지표 | dot plot / bar | 23개 개별 값을 순서 없이 또는 필요시만 정렬해 보여주기에 적합. 파이차트처럼 전체=100%를 암시하지 않음 |
| Direct Gap / Conditional Gap | dumbbell(두 점+연결선) | 두 지표(경험률-의향률)의 값과 그 차이를 동시에 보여줌 — 막대 하나로 압축하면 "차이"만 남고 원래 두 값이 사라짐 |
| 8개 장벽 × 23개국 | heatmap | 국가×장벽의 2차원 비교를 한 화면에 담을 수 있음. 색상 강도는 절대적 위험도가 아니라 상대적 응답 비율임을 범례에 명시 |
| 국가 프로파일(Type A~G) | profile card / 매트릭스(체크박스 형태) | 국가가 여러 유형에 동시에 속할 수 있다는 사실을 "체크된 항목 여러 개"로 직관적으로 표현 — 막대 하나로 압축하면 복수 소속이 사라짐 |
| 국가 비교 | 병렬 카드 + 그룹 bar | 레이더 차트는 축마다 스케일이 달라(%p vs %) 시각적으로 "면적이 큰 게 좋다"는 잘못된 인상을 줄 수 있어 배제 |
| Direct Gap × 장벽 산점도 | 라벨 포함 scatter | 상관의 방향/강도를 보여주되 개별 국가를 식별 가능하게 하여 "선형관계 하나"로 뭉개지 않음 |

## 7. 대시보드에서 사용하지 않는 표현 (전 화면 공통)

금지: "전환율", "원인", "영향", "효과", "가장 공략해야 할 국가", "우선순위 국가", "병목이 확정되었다",
"장벽이 Gap을 발생시킨다", 국가 순위(1위~23위) 언어.

대신 사용: "관찰", "Gap(관찰값)", "패턴", "병목 가능성", "장벽 응답(방문 비의향자 기준)", "연관(상관)",
"참고", "상대적 위치(tercile)".

이 표현 규칙은 `ai_analysis_interface_spec.md`의 AI 응답에도 동일하게 적용된다.
