# 최종 분석 프레임 (Dashboard/AI 공통 기준)

이 문서는 지금까지 수행한 모든 분석(구조 분석 → PDF 교차검증 → 핵심 데이터 추출 → 국가 매칭/BASE 비교 →
분석 프레임 확정 → analysis_long.csv 구현 → 국가별 패턴/병목 프로파일링 → Gap 검증 → Gap-장벽 관계/민감도 →
병목 유형화)를 하나의 최종 프레임으로 정리한 것이다. 대시보드와 AI 분석 인터페이스는 **이 문서에 정의된 개념과
해석 규칙만**을 사용한다. 여기 없는 새로운 지표·기준값·해석은 만들어내지 않는다.

## 0. 프로젝트의 핵심 질문

> "어떻게 하면 감에 의존한 기획에서 벗어나, 국가별 실제 수요와 한국에 대한 인식의 간극을 데이터로 발견하고
> 새로운 사업 기회로 연결할 수 있을까?"
>
> (2026-08-26 개정 — 이전 질문: "한류/한국문화에 대한 경험과 관심이 실제 한국 방문의향으로 이어지는 과정에서,
> 국가별로 어떤 패턴과 차이가 나타나는가?")

이 프로젝트는 한류/한국문화 인식과 실제 방한 행동 사이에서 국가별로 관찰되는 간극(Gap)을 근거로, 새로운
사업 기회를 발굴하는 것을 목적으로 한다. 다만 실제 사업 담당자는 보통 특정 권역/국가를 전담하므로, "다른
국가가 더 기회다"는 국가 간 우열 비교는 실무에 도움이 되지 않는다. 그래서 아래처럼 범위를 좁혀 정한다
(2026-08-26 논의 결론):

- **허용**: 이미 계산된 개별 지표(Gap 크기, 특정 장벽 %, tercile 등) 기준으로 23개국을 정렬/필터링해서
  보여주는 것. 예: "Direct Gap이 큰 순서로 보기". 이건 있는 데이터를 그대로 다른 순서로 보여줄 뿐이다.
- **허용**: 특정 국가 하나를 깊이 파고들 때, 그 국가 안에서 어떤 패턴(어느 장벽이 크고, Gap이 상대적으로
  어느 tercile인지)이 관찰되는지 설명하고 사업 기회를 시사하는 것.
- **금지**: Gap·장벽·상관관계 등 서로 다른 지표를 임의로 가중합쳐 "종합 기회 점수" 같은 새 합성 지표를
  만드는 것. 가중치 선택 자체가 근거 없는 "감"이 되기 때문이다.
- **금지**: "A국보다 B국이 더 기회다" 식으로 국가 간 우열을 비교/결론짓는 것. 각 국가는 그 국가를 보는
  사람 기준으로 독립적으로 설명한다.
- 5절의 데이터 해석 규칙(BASE 표시, comparability 구분, 상관≠인과, tercile은 상대적 위치일 뿐 등)은 위
  정렬/필터·국가별 설명에도 예외 없이 적용된다.

## 1. Layer 구조

### Layer 1 — 문화/한류 경험
- 지표: `culture_experience_rate_pct` (E1A-1, 문화경험률)
- BASE: 잠재방한객조사(일반외국인) 전체 응답자 (n=16,360)
- 의미: 응답자가 한국 문화 콘텐츠를 경험한 적이 있다고 답한 비율
- 의미하지 않는 것: 경험의 깊이·빈도·최근성은 포함하지 않음. "한류 팬"과 동일시하지 않음.

### Layer 2 — 한국에 대한 인식/호감
- 지표:
  - `culture_to_korea_positive_pct` (E4-1, 문화경험→호감도 긍정률) — BASE: 문화경험자(전체의 하위집합)
  - `hallyu_perception_positive_pct` (1-35, 한류실태 인식긍정률) — BASE: 한류실태조사의 별도 패널(한류 경험자 전용)
- 의미: 문화 경험 이후 한국에 대해 갖는 긍정적 인식의 비율
- 의미하지 않는 것: 1-35는 잠재방한객조사와 **다른 모집단**에서 수집된 값이므로, E4-1과 같은 조사의 연속된
  단계처럼 다루지 않는다. 두 지표를 나란히 보여줄 수는 있지만 하나로 합치지 않는다.

### Layer 3 — 방한의향/방문의향
- 지표:
  - `visit_intention_positive_pct` (B5B-1, 방한의향 있음률) — BASE: 전체 응답자 (n=16,360)
  - `culture_to_visit_positive_pct` (E4-3, 문화경험→방문의향 긍정률) — BASE: 문화경험자(전체의 하위집합)
- 의미: 응답자가 한국 방문 의향이 있다고 답한 비율(경로에 따라 BASE가 다름)
- 의미하지 않는 것: "방문 확정"이나 "예약 의사"가 아니라 설문 시점의 의향 응답.

## 2. Gap — 두 축을 절대 하나로 합치지 않음

### Direct Gap (E1A-1 ↔ B5B-1)
- 정의: `문화경험률(%) - 방한의향률(%)`
- BASE: 두 지표 모두 **동일한 전체 응답자(n=16,360)** — 23개국 핵심 지표 중 동일 BASE를 공유하는 유일한 쌍
- comparability: `direct_within_survey`
- 의미: 같은 모집단 안에서 "문화를 경험했다"는 응답과 "방한 의향이 있다"는 응답 비율의 단순 차이(percentage
  point)
- 의미하지 않는 것: 개인이 경험 후 의향으로 "전환되지 못한 비율"이 아님(같은 응답자가 두 문항에 동시에 응답했다는
  전제가 없으면 개인 단위 전환으로 확장할 수 없음). 원인이나 인과관계를 의미하지 않음.

### Conditional Gap (E4-1 ↔ E4-3)
- 정의: `문화→호감도 긍정률(%) - 문화→방문의향 긍정률(%)`
- BASE: 두 지표 모두 **문화경험자라는 동일 하위집합**
- comparability: `conditional`
- 의미: 문화경험자 하위집단 안에서 호감도 응답과 방문의향 응답 비율의 단순 차이
- Direct Gap과의 관계: **별개의 분석축**이다. E1A-1→E4-1→E4-3→B5B-1을 하나의 funnel이나 전환율로 합친 적이
  없고, 앞으로도 합치지 않는다. 두 Gap이 국가 단위에서 함께 나타나는 경향(상관 r=0.311, p=0.149, 전체
  23개국)이 관찰된 적은 있으나, 이는 "관찰"일 뿐 하나의 지표로 통합할 근거가 아니다.

### 1-35는 Gap 계산에서 제외
한류실태조사(1-35)는 잠재방한객조사와 모집단이 다른 별도 패널이므로, 어떤 지표와도 직접 차감(Gap 계산)하지
않는다. 국가 프로파일의 참고 정보로만 사용한다.

## 3. Barrier — 방문 비의향자 하위집단의 응답

- 원천: B13-1A(주된 비의향 사유), B13-2A
- BASE: **방문 비의향자**(전체 응답자의 하위집합, 국가마다 표본 크기가 다름)
- 8개 원문 항목(분석 편의를 위해 5개 그룹으로 묶었으나 원문 항목 자체는 변경하지 않음):
  - 인지/관심: 낮은 한국 인지도, 한류 관심 부재
  - 이미지: 부정적인 한국 이미지
  - 경제/물리적 접근성: 여행경비/물가, 장거리 비행
  - 제도/언어: 비자/출입국 절차, 불편한 언어소통
  - 종교/문화환경: 불편한 종교 환경
- 의미: 방문 비의향자들이 선택한 사유의 응답 비율
- 의미하지 않는 것: 해당 국가 "전체 인구"나 "전체 잠재 방한객"의 성향이 아님. 방문 비의향자만의 응답.
- 소표본 주의: 베트남(9명), 인도네시아(17명), 태국(28명), 필리핀(21명)은 표본 30명 미만 — 이 4개국의 장벽
  수치는 국가 간 비교의 강한 근거로 사용하지 않는다.

## 4. Country Profile — 국가별 관찰 패턴과 병목 유형

- Gap 기반 유형(재인용값, 별도 계산 없음):
  - Type A = Direct Gap 상위3분위 (7개국: 러시아, 멕시코, 미국, 인도, 카자흐스탄, 태국, 튀르키예)
  - Type B = Conditional Gap 상위3분위 (7개국: 독일, 러시아, 미국, 브라질, 영국, 태국, 호주)
- 장벽 기반 유형(방문 비의향자 BASE, tercile):
  - Type C = 인지/관심 장벽 상위3분위 (13개국)
  - Type D = 이미지 장벽 상위3분위 (7개국)
  - Type E = 경제/물리적 접근성 장벽 상위3분위 (10개국)
  - Type F = 제도/언어 장벽 상위3분위 (13개국)
  - Type G = 종교/문화환경 장벽 상위3분위 (7개국)
- 한 국가는 여러 유형에 동시에 속할 수 있다(예: 미국은 A+B+C+D+E+F, 6개 유형).
- 의미: 관찰값 조합을 사람이 읽을 수 있게 규칙으로 묶은 **서술적 분류**
- 의미하지 않는 것: 군집분석 등 통계적 방법으로 확인된 자연발생적 군집이 아님. Type C/F는 두 장벽의 OR
  조건이라 23개국의 56.5%를 포함해 국가 구별력이 상대적으로 약함(`bottleneck_type_summary.csv` 참조).

## 5. 데이터 해석 규칙 (대시보드/AI 공통, 반드시 준수)

1. **BASE를 항상 함께 표시한다.** 모든 지표·Gap·장벽 수치는 어떤 BASE(전체 응답자 / 문화경험자 / 방문
   비의향자 / 한류실태조사 별도 패널)에서 나왔는지 표시한다.
2. **comparability를 구분한다.** `direct_within_survey`(E1A-1↔B5B-1)와 `conditional`(그 외 모든 지표쌍)을
   섞어서 서술하지 않는다.
3. **표본 수와 소표본 여부를 표시한다.** 장벽 지표는 국가별 방문 비의향자 표본 수가 다르며, 30명 미만은
   "소표본 주의" 표시를 유지한다.
4. **서로 다른 BASE의 값을 직접 차감하지 않는다.** Direct Gap과 Conditional Gap 외에는 어떤 지표 쌍도 새로
   차감(Gap)하지 않는다.
5. **1-35와 잠재방한객조사 지표 사이의 직접 Gap을 계산하지 않는다.** 모집단이 다른 별도 패널이기 때문이다.
6. **장벽은 방문 비의향자 하위집단의 응답이라는 점을 항상 명시한다.** 국가 전체 성향으로 일반화하지 않는다.
7. **국가 단위 집계값으로 개인 단위 인과관계를 주장하지 않는다.** 모든 지표는 국가 단위 집계값이며, 개인이
   실제로 "경험 → 인식 → 의향"으로 전환되었는지는 이 데이터로 확인할 수 없다.
8. **상관관계를 인과관계로 해석하지 않는다.** `gap_barrier_correlation.csv`의 Pearson/Spearman 값은 국가
   단위 집계자료 사이의 통계적 관계일 뿐이며, p-value가 낮아도 "유의하다"고 단정하지 않고 "원인이다/영향을
   준다/전환을 유발한다"는 표현을 쓰지 않는다.
9. **tercile(3분위)은 상대적 위치이지 절대적 좋음/나쁨이 아니다.** "상위3분위"는 23개국 중 상대적으로 높다는
   뜻이며, 객관적으로 문제라는 뜻이 아니다.
10. **Type A~G는 통계적으로 확정된 자연발생적 군집이 아니다.** 규칙 기반 프로파일이며, 다음 단계(군집분석 등)
    에서 검증이 필요한 가설로 취급한다.

## 6. 지금까지의 분석을 대시보드 노출 수준으로 분류

### A. 대시보드 핵심 노출 (Overview / Country Explorer 기본 화면)
- Layer 1~3 6개 핵심 지표의 국가별 값과 23개국 분포 (`country_profile_base.csv`,
  `country_indicator_distribution.csv`)
- Direct Gap, Conditional Gap 국가별 값과 분포 (`gap_analysis.csv`, `conditional_gap_analysis.csv`)
- 국가별 상위 장벽 Top3 및 8개 장벽 전체 비율 (`barrier_pattern_analysis.csv`)
- 국가별 병목 프로파일(Type A~G 플래그, 관찰 패턴 요약) (`country_bottleneck_profile.csv`)

이유: 프로젝트의 핵심 질문("경험 → 의향으로 이어지는 과정에서 국가별 패턴과 차이")에 직접 답하는 값들이며,
사용자가 대시보드에 처음 들어왔을 때 봐야 하는 정보다.

### B. 보조 분석 (탐색 시 필요할 때 펼쳐보는 화면)
- 한류실태조사 인식긍정률(1-35) 참고값 — 별도 패널이라는 점을 함께 표시하는 조건으로 보조 노출
- Gap-장벽 상관표(`gap_barrier_correlation.csv`) — Pearson/Spearman, 방향, p-value
- 소표본 민감도 비교(`sensitivity_analysis.csv`) — 소표본 포함/제외 시 상관계수 변화
- 유형 요약표(`bottleneck_type_summary.csv`) — 유형별 국가 수, 중복, 구별력

이유: 프로젝트의 핵심 질문에 직접 답하지는 않지만, "이 패턴을 어디까지 신뢰할 수 있는가"를 사용자가 스스로
검토하고 싶을 때 필요한 정보다. 기본 화면에 항상 띄우면 정보 과잉이 된다.

### C. 내부 검증용 (기본 화면에 노출하지 않음)
- `analysis_long.csv`, `validation_report.md` — 원천 롱포맷 데이터와 QA 로그
- `gap_validation_report.md`, `gap_barrier_validation_report.md`, `country_pattern_analysis_report.md`,
  `bottleneck_typology_report.md`의 방법론/재현 절차 서술 부분
- 국가 매핑/지표 매핑 검증 자료(`potential_hallyu_country_mapping.csv`,
  `potential_hallyu_indicator_mapping.csv`, `potential_tourist_extraction_validation.csv` 등 이전 단계 산출물)

이유: 분석의 재현성과 신뢰성을 담보하기 위해 반드시 보존해야 하지만, 최종 사용자가 매 화면에서 볼 필요는
없다. AI Analyst가 "이 수치의 근거가 뭐야?"라는 질문에 답할 때 참조하는 배경 자료로 취급한다.

## 7. 마지막 정리

1. **이 프로젝트가 최종적으로 답하려는 질문**: 감에 의존한 기획에서 벗어나, 국가별 실제 수요와 한국에 대한
   인식의 간극을 데이터로 발견하고 새로운 사업 기회로 연결하는 것 (0절 참고). 개별 지표 기준 정렬/필터와
   국가 하나에 대한 깊이 있는 설명은 허용하되, 합성 "기회 점수"나 국가 간 우열 비교는 만들지 않는다 (0절의
   허용/금지 목록 참고).
2. **현재까지 데이터로 확인된 것**: 23개국 각각의 Layer1~3 지표 값과 상대적 위치(tercile), 동일 BASE를
   공유하는 두 지표쌍(E1A-1↔B5B-1, E4-1↔E4-3)의 관찰 Gap, 방문 비의향자 하위집단의 8개 장벽 응답 비율,
   이 값들을 조합한 국가별 병목 프로파일(Type A~G), 그리고 Direct Gap과 일부 장벽(여행경비/물가, 낮은 한국
   인지도, 부정적 한국 이미지) 사이에서 국가 단위로 관찰되는 상관 경향.
3. **아직 확인할 수 없는 것**: 장벽과 Gap 사이의 인과관계, 개인 단위의 실제 전환 여부, Type A~G가 통계적으로
   유의미하게 구분되는 집단인지, 소표본 4개국의 실제 특성, tercile 구간 차이의 통계적 유의성, 관찰된 상관이
   표본설계 차이가 아닌 실제 국가 특성 차이에서 비롯되는지.
